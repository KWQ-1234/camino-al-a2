# 前期课程格式 v2（第 1–10 周，键 w{周}d{1-5}）

比 v1 多三样：`recap`（上一课回顾）、`steps`（讲解分小步，每步后跟 2 道即时练习）、例句必须带拆解。**例句只能用学过的词**：每个词要么出现在之前课程的 vocab 里，要么是本课 vocab；人名和标点除外。用 `node check2.js` 校验，必须零违规。

```js
window.LESSONS = Object.assign(window.LESSONS || {}, {
w3d1: {
  title: "我是……：soy",                       // ≤ 14 字
  goal: "学完能说「我是 Ana」「我叫 Ana」。",     // 一句话，只说一件事
  recap: [                                      // 3 道上一课的回顾题，{q, a, opts?}
    { q: "上一课：15 用西语怎么说？", a: "quince" },
  ],
  steps: [                                      // 2–3 个小步；每步 = 讲解块 + 2 道即时练习
    { explain: [
        { p: "段落，可用 **粗体**。" },
        { table: { head: ["…"], rows: [["…"]] } },
        { tip: "提示。" }
      ],
      check: [                                  // 恰好 2 道，做完才能看下一步
        { q: "填空：___ Ana.（我是）", a: "Soy" },
        { q: "选择：me llamo 里的 llamo 来自哪个动词？", opts: ["llamar", "llamo", "ser"], a: "llamar" }
      ]
    },
  ],
  examples: [                                   // 5–6 句，[西语, 中文, 拆解]；拆解逐词：词（意思，来历）
    ["Hola, soy Ana.", "你好，我是 Ana。", "hola（你好）+ soy（我是，ser 的「我」形式）+ Ana。"],
  ],
  vocab: [                                      // 6–8 条，[西语, 中文, 备注]；全部要在例句里出现过
    ["soy", "我是", "ser 的「我」形式"],
  ],
  exercises: [ { q, a, opts? } ],              // 6 道
  task: "听说任务，一句话。"
}
});
```

写作规则：
- 一课只讲一件事。宁可少，不可跳。
- 讲解面向完全零基础的中文使用者：每个新形式都要说明从哪里来、为什么是这样。
- 第 1–2 周名词先不带冠词（冠词第 5 周学），备注写「冠词第 5 周学」。第 5 周起名词带 el/la。
- 例句里出现的每个词都必须能在词表里查到；固定句可以整句作为一条 vocab（如「¿Cómo se escribe?」），它的每个词就算教过了。
- 备注里的读音用「大写音节 = 重音」的写法，如 [ME-sa]；第 1 周所有词都写读音。
