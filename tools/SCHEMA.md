# 课程数据格式（每课一个对象，键为 w{周}d{1-5}）

文件必须是合法 JS，形如：

```js
window.LESSONS = Object.assign(window.LESSONS || {}, {
  w5d1: { ... },
  w5d2: { ... },
});
```

每课字段（全部必填，除 opts）：

```js
w5d1: {
  title: "gustar 的逻辑",                 // 课名，≤ 14 字
  goal: "学完能说出 5 句自己喜欢什么。",     // 一句话目标
  explain: [                              // 讲解块，3–6 块，总量约 250–400 汉字
    { p: "段落。可以用 **粗体** 强调。西语示例直接写在句中，如 me gusta el café。" },
    { table: { head: ["人称","代词","例句"], rows: [["我","me","me gusta"],["你","te","te gusta"]] } },
    { tip: "常见错误或记忆提示，一两句。" }
  ],
  examples: [                             // 6–8 句，[西语, 中文]。句子要自然、可朗读、只用已学过或本课教的语法
    ["Me gusta el café.", "我喜欢咖啡。"],
  ],
  vocab: [                                // 10–12 条，[西语, 中文, 备注]。备注可写发音重音、性别、搭配；名词带冠词 el/la
    ["el café", "咖啡", "重音在 fé"],
  ],
  exercises: [                            // 6–8 题，{q, a, opts?}。q 是题目，a 是标准答案（简短）。有 opts 时为单选，a 必须是 opts 之一
    { q: "填空：___ gusta el té. (我)", a: "Me" },
    { q: "选择：A mí ___ gusta bailar.", opts: ["me","mí","yo"], a: "me" },
    { q: "翻译：我喜欢音乐。", a: "Me gusta la música." },
  ],
  task: "听说任务：一句话，说清楚做什么、多久。"   // 例：跟读全部例句 2 遍，然后录 5 句自己的喜好。
}
```

规则：
- 讲解面向中文母语零基础者，用中文解释，术语第一次出现给西语原名。
- 只用到本课及之前课程教过的语法；例句和练习避免超纲。
- 西语拼写和重音符号必须正确；ñ、¿、¡ 正常使用。
- 词性：名词写成 el/la + 名词；形容词写 -o/-a 形式（如 cansado/a）。
- 不要写 lorem 或占位；不要在 p 里放 HTML。
- 词汇尽量不与前面课程重复（前面课程的词汇表见 vocab-index.txt）。
