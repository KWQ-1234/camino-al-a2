# 第 5–10 周大纲（新版前期，每课只讲一件事）

学习者状态：已完成第 1–4 周（见 vocab-w1-4.txt）：全部发音、字母表、问候与礼貌用语、数字 0–20、ser 全表（soy/eres/es/somos/sois/son）、me llamo/te llamas/se llama、soy de + 国家、国籍阴阳性、6 个职业、usted。还**没有**学：冠词、名词性别规则、复数规则（只在 w4d3 提过 -s/-es）、estar、tener、hay、任何规则动词、形容词（除国籍）、疑问词（只有 quién/cómo/dónde/qué/cuánto 在固定句里出现过）。

## 第 5 周 · 东西与地方 I
- w5d1 名词的性别与 el / la：-o 阳性、-a 阴性，8 个物品（重新带冠词教 mesa、casa 等已学名词也可以）；例外 el día、la mano
- w5d2 un / una 与 hay：「有一个……」，hay 只有一个形状，hay 后不接 el/la
- w5d3 复数：-s / -es / -z→-ces，los / las / unos / unas，hay muchos
- w5d4 estar 表位置 I：está（它在）+ en + 地点；¿Dónde está…?
- w5d5 estar 表位置 II：estoy / estás，¿Dónde estás? — Estoy en casa；aquí / allí；第 5 周复习

## 第 6 周 · 东西与地方 II
- w6d1 estar 全表（estoy estás está estamos estáis están）+ cerca de / lejos de / del
- w6d2 ser 还是 estar I：身份、来源、职业 vs 位置
- w6d3 6 个形容词（grande, pequeño/a, bonito/a, nuevo/a, bueno/a, caro/a）与性数一致，放在名词后
- w6d4 estar + 状态形容词（cansado/a, contento/a, triste, enfermo/a, ocupado/a），¿Cómo estás? — Estoy bien；ser 还是 estar II
- w6d5 hay 还是 está；第 6 周复习

## 第 7 周 · 我有
- w7d1 tengo / tienes + 物品；¿Tienes…? — Sí, tengo… / No, no tengo…
- w7d2 tener 全表 + 家庭成员（padre, madre, hermano/a, hijo/a, abuelo/a）+ mi / mis / tu / tus
- w7d3 数字 21–100 + tener … años（¿Cuántos años tienes?）
- w7d4 tener hambre / sed / frío / calor；muy / mucho
- w7d5 介绍家庭；第 7 周复习

## 第 8 周 · 动作 I（规则动词）
- w8d1 -ar 动词只学 yo / tú：hablar, estudiar, trabajar（hablo / hablas）
- w8d2 -ar 动词 él / nosotros / ellos，全表；再加 5 个 -ar 动词
- w8d3 -er 动词全表：comer, beber, leer, aprender
- w8d4 -ir 动词全表：vivir, escribir, abrir；¿Dónde vives?
- w8d5 三类动词对照表；第 8 周复习

## 第 9 周 · 提问、时间、否定、去
- w9d1 疑问词系统：qué / quién / dónde / cuándo / cómo / por qué（porque）/ cuánto
- w9d2 钟点：¿Qué hora es? es la una / son las dos，y cuarto / y media / menos cuarto；¿A qué hora…?
- w9d3 否定与简短回答：no + 动词、nunca、nada、nadie、también / tampoco
- w9d4 ir 全表 + al；ir a + 原形 表将来；hoy / mañana / esta noche
- w9d5 hacer / poder / querer（hago；puedo o→ue；quiero e→ie）+ 原形

## 第 10 周 · 场景与第一阶段总复习
- w10d1 saber / conocer / poder 的分工；人称 a
- w10d2 在餐厅：quisiera, para mí, la cuenta, ¿cuánto es?；食物词
- w10d3 频率与作息词：siempre / a veces / nunca，por la mañana / tarde / noche；todos los días
- w10d4 总复习 I：ser / estar / tener / hay 对照 + 动词总表
- w10d5 总复习 II：里程碑 1 —— 2 分钟自我介绍 + 描述家和家人 + 说一天做什么
